# amago-app-v0

Protótipo inicial (v0) do aplicativo Âmago, desenvolvido em Python, com foco na promoção de hábitos saudáveis por meio de trilhas gamificadas. Esta versão implementa a trilha de hidratação (consumo de água), incluindo etapas de estudo, exercícios e prática, com armazenamento de dados em Firebase Realtime Database.

## Objetivo acadêmico

Projeto desenvolvido para a disciplina **Desenvolvimento de Produto II**.

## Tecnologias utilizadas

- Python
- Firebase Realtime Database
- Git/GitHub

## Funcionalidades da versão v0

- Anamnese básica
- Trilha de hidratação com 3 estudos, 3 exercícios e 3 práticas
- Registro de consumo de água
- Feedback simples ao usuário

## Estrutura inicial

- `src/`: código do aplicativo
- `docs/`: documentação, UML e descrições
- `prints/`: imagens do sistema para o trabalho
- `config/`: arquivos de configuração, Firebase e credenciais
